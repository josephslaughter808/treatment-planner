Revised asset study

Real human meshes with permanent modesty coverage.

This page now starts with the exact body-region mesh ClearPath uses today. It also separates what is already in the app from candidate assets so we do not mistake a reference model for a production decision.

Production safety requirement

Garments must be fused into the deliverable model. Covered chest and pelvic geometry must be deleted, not merely hidden, so no child or adult can reveal an explicit layer through controls, browser tools, or asset inspection. Pediatric accounts should use the same neutral adult-style map rather than a realistic child body model.

Current decision: James leads for realism; the Procreate bundle leads for the matched pair.

The bundle solves the modesty problem at the geometry level and gives us both body forms in one style. Before purchasing or embedding it, we need written confirmation that its royalty-free license permits modified OBJ geometry to be delivered to a web browser, plus a technical inspection of topology, region separation, pose, and mobile performance.
