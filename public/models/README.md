# Anatomical Model Attribution

The interactive body view loads the Z-Anatomy regional body model directly
from the project's official GitHub repository. The model was created by Lluis
Vinent Juanico and contributors.

- Source: https://github.com/Z-Anatomy/Unity-app_Z-Anatomy
- Original file: `Resources/Models/FBX/Regions of human body100.fbx`
- Runtime URL: https://raw.githubusercontent.com/Z-Anatomy/Unity-app_Z-Anatomy/PC-Version/Resources/Models/FBX/Regions%20of%20human%20body100.fbx
- License: Creative Commons Attribution-ShareAlike 4.0 International
- License URL: https://creativecommons.org/licenses/by-sa/4.0/

The model is used as an interactive anatomical navigation surface. ClearPath
condition data, selection behavior, coloring, rendering, and application code
are separate additions. The model must not be presented as a diagnostic tool
or as a substitute for clinician interpretation.
