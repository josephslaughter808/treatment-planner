# USDA DLT Funding Research

## Current Conclusion

The FY2026 Distance Learning and Telemedicine program is a real deployment grant for rural sites. It can fund software, network components, equipment, and limited technical assistance, but it is not a general startup R&D award.

## Documents

- [USDA DLT Deep Dive](./usda-dlt-deep-dive.md)
- [USDA DLT Source Register](./source-register.md)

## Preliminary Decision

Do not attempt the June 30, 2026 deadline without an already organized rural consortium. Use the program as a 2027 deployment target and begin Texas rural-provider discovery now.
