# NLM Funding Research

## Current Conclusion

The National Library of Medicine is the strongest NIH home for ClearPath. Its small-business interests expressly include biomedical informatics tools, software platforms, biomedical data infrastructure, trustworthy systems, and human-centered informatics.

The current direct route is NIH Parent SBIR `PA-27-100`. Phase I applications are accepted by participating institutes through April 6, 2027, with standard NIH dates generally September 5, January 5, and April 5, adjusted for weekends and federal holidays.
