# NIDILRR Funding Research

## Current Conclusion

NIDILRR operates an annual SBIR program for products that improve the lives of people with disabilities. ClearPath could fit only through authentic disability-centered co-design and outcomes.

## Preliminary Decision

Monitor the annual Phase I release and conduct disability-community discovery before deciding whether to apply. The current general platform is not yet sufficiently disability-specific.
