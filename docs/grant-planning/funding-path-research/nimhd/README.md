# NIMHD Funding Research

## Current Conclusion

NIMHD is a strong overlooked NIH option. Its current small-business interests expressly include EHR and biomedical-informatics platforms, patient-clinician communication, digital health, telehealth, and technologies that improve healthcare access for populations experiencing health disparities.

## Preliminary Decision

Request a program consultation. NIMHD should become a top-three NIH option only if ClearPath commits to a specific disparity population, community-engaged research, and measurable equity outcomes.
