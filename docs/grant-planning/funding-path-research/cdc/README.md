# CDC Funding Research

## Current Conclusion

CDC participates in the current NIH/CDC Parent SBIR `PA-27-100`. It funds commercializable technology that answers a CDC public-health research priority. Phase I may be up to $323,090 and Phase II up to $2,153,927, subject to the announcement and CDC topic rules.

ClearPath is not automatically a CDC project merely because it handles health information. A credible application must focus on a public-health function such as surveillance, reportable data, outbreak response, occupational health, prevention, or population-level coordination.
