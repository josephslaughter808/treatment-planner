# Patient Health Information Software Exchange Research Matrix

## Purpose

This matrix extends the software market map by tracking likely export and import paths for each platform. It is meant for connector planning, not as a final legal or technical integration promise.

## Confidence Legend

- High: documented or widely established integration path.
- Medium: likely integration path based on product category, standards, or known market behavior, but still needs vendor/customer confirmation.
- Low-Medium: useful planning assumption for smaller or specialty systems; must be verified before quoting to a customer.
- Low: placeholder research row only.

## Product Principle

ClearPath should not become 548 one-off products. The product should remain one patient-controlled hub that can package data into different transport formats: human-readable PDF, ClearPath JSON, FHIR Bundle, HL7/interface payload, CSV, document package, or vendor-specific reviewed import.
